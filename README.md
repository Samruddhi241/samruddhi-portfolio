Samruddhi Kapadnis | Portfolio

A responsive, dark-themed personal portfolio website with purple/blue gradients, glassmorphism and smooth animations.

Sections
Home: animated introduction
About Me: summary, achievements, co-curricular activities and languages
Skills: expandable skill cards
Projects: clickable cards that open a detailed popup
Education: current degree and college
Certifications: expandable certificate cards
Contact: email, GitHub and LinkedIn
Projects featured
Q-link Pharma: AI & quantum-inspired drug distribution optimizer
Bill Decoder: AI-powered government bill simplifier
Stitch It Up: tailor management system
Built with
React 18 (loaded from a CDN)
htm (JSX-like templates, no build step)
HTML and CSS
Google Fonts: Sora and Manrope

The whole site lives in one file, index.html, so there is nothing to install or build.

Run locally
Download index.html.
Double-click it to open it in your browser (an internet connection is needed to load React and the fonts).
Deploy for free
GitHub Pages
Create a new repository named portfolio.
Upload index.html and this README.md.
Go to Settings → Pages.
Under Branch, choose main and / (root), then click Save.
After a minute, the site is live at https://samruddhi241.github.io/portfolio.
Netlify Drop
Put index.html in a folder.
Go to app.netlify.com/drop and drag the folder onto the page.
Netlify gives you a live link, which you can rename in Site settings.
Customize

Open index.html in any text editor. The content is near the top of the script, in the SKILLS, PROJECTS and CERTS lists. Edit the text, save, and upload the file again.
